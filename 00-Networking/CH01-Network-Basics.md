# CH-01: Network Basics

## Definition
**Network** — Two or more computers connected 
together to share resources and data between 
each other.

## Types of Networks

**LAN (Local Area Network)** — A network within 
a small area.
- Example: Home / Office

**WAN (Wide Area Network)** — A network that 
spans large geographical areas connecting 
multiple LANs.

**MAN (Metropolitan Area Network)** — A network 
that covers a city.
- Example: Hyderabad

## Internet
Scaling up a network is called Internet.
- Example: Millions of computers connected 
  together.

## Intranet
A private network using TCP/IP stack within 
an organization. Not accessible from internet.

## Pentesting Relevance
Understanding network types helps identify 
scope and scale during reconnaissance phase 
of a pentest engagement.
